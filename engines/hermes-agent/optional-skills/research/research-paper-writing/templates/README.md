# Conference templates: download them from the official sources

The upstream Hermes skill bundled LaTeX style files, bibliography styles and example PDFs from
AAAI, ACL, COLM, ICLR, ICML and NeurIPS. Those files belong to the conference organisers and carry
no redistribution license, so ReWoo's vendored copy does **not** include them.

Get the current official kits here and unpack them into this folder with the same names
(`aaai2026/`, `acl/`, `colm2025/`, `iclr2026/`, `icml2026/`, `neurips2025/`):

| Venue | Official author kit |
|---|---|
| AAAI | https://aaai.org/authorkit/ |
| ACL / *ACL | https://github.com/acl-org/acl-style-files |
| COLM | https://github.com/COLM-org/Template |
| ICLR | https://github.com/ICLR/Master-Template |
| ICML | https://icml.cc/ (Author instructions → style files) |
| NeurIPS | https://neurips.cc/ (Call for Papers → style files) |

The rest of the skill (instructions, checklists) is unchanged and MIT-licensed as part of Hermes Agent.
