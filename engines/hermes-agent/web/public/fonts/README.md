# Fonts removed from this vendored copy

The upstream Hermes Agent website shipped these font files here:
`Collapse-*`, `RulesCompressed-*`, `RulesExpanded-*` (© Blaze Type, https://blazetype.eu) and
`Mondwest-Regular` (© Pangram Pangram Foundry).

They are commercial typefaces marked "All rights reserved", and no redistribution license is
included, so ReWoo does **not** redistribute them. The Hermes website (`engines/hermes-agent/web`) falls
back to system fonts without them. If you build that website, buy the appropriate licences from the
foundries and place the files here. Nothing in ReWoo itself uses these fonts.
