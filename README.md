## Universe ✨

Universe is an independent, open-source AI workspace. This repository
currently hosts the **chat frontend (milestone 1)** — a local demo prototype
built with React, TypeScript, and Vite.

### Try the frontend

```bash
cd frontend
npm install
npm run dev
```

See [`frontend/README.md`](frontend/README.md) for setup, architecture, and
commands; [`frontend/docs/`](frontend/docs) for the reference audit, design
tokens, conversation model, roadmap, verification results, and feature-status
matrix.

Everything in this milestone runs locally: responses come from a
deterministic demo adapter, conversations persist in your browser, and no
provider, account, or backend is involved.
